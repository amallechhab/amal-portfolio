DEAL App
Application de petites annonces

Notre projet de groupe : un prototype web responsive pour consulter, rechercher et explorer des petites annonces. Il est réalisé en HTML, CSS et JavaScript et dispose d'une version en ligne et d'un dépôt GitHub.

Notre projet

Présentation de DEAL

DEAL est un prototype de site de petites annonces pour les catégories voitures, immobilier, téléphones et mode. Le dépôt décrit la conception du Sprint 1, les User Stories et l'organisation avec Figma, Jira, Git et GitHub.

HTMLCSSJavaScriptResponsive
État réel

Prototype, pas application complète

Les pages de consultation, de recherche, de détail et de connexion sont présentes dans le code. Les annonces visibles sont des données de démonstration. Selon le README du dépôt, l'authentification et la base de données ne sont pas reliées à la version principale de ce prototype.

Une mise en ligne réussie ne prouve pas que toutes les User Stories sont implémentées.

Mon rôle dans le groupe

Responsable / Coordinatrice de DEAL App

Notre groupe était composé de 5 stagiaires. En tant que responsable du groupe, j'ai organisé le travail collectif et réparti les tâches entre les quatre autres membres.
