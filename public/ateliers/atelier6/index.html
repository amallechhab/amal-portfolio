Objectifs

Le travail de l'atelier

Développer une application Full Stack simple pour écrire des informations dans une base MySQL sur Aiven, transférer des photos vers Cloudinary, lire les données et préparer le déploiement Vercel.

Cette application prépare le Sprint 3 du projet Quick Annonces : il ne s'agit pas de la partie collective de planification des annonces.

Ce qui existe dans mon dépôt

Mon application

Le dépôt contient un formulaire HTML, une page de liste, des fonctions PHP, la configuration et une présentation du projet. L'existence de ces fichiers ne prouve pas à elle seule que MySQL, Cloudinary et les inscriptions fonctionnent en production.

PrésentationCode GitHub
Architecture pédagogique

Comment l'application est organisée

NavigateurFormulaire + liste HTML
PHP sur VercelValidation, inscription, lecture
Aiven MySQLInformations des stagiaires
CloudinaryPhotos hébergées et URL

Le navigateur envoie les données au backend PHP. PHP communique avec MySQL et Cloudinary côté serveur. Les données relationnelles restent dans MySQL, et les images sur Cloudinary.

ÉTAPE 9 / 9

Configurer les variables et déployer sur Vercel

Publier les pages et configurer les services externes côté serveur.

Travail demandé

  1. Ajouter les variables DB_HOST, DB_PORT, DB_NAME, DB_USER et DB_PASSWORD dans Vercel.
  2. Ajouter CLOUDINARY_URL dans les variables d'environnement côté serveur.
  3. Configurer les environnements concernés puis redéployer l'application.
  4. Tester l'inscription, la lecture depuis MySQL et l'affichage de la photo Cloudinary.
