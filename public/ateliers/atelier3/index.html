Les bases de Git

Découvrir Git en créant un dépôt local, en enregistrant plusieurs versions de fichiers et en consultant l'historique du projet.

Travail individuel · Captures et réponses à compléter

Objectif pédagogique

Ce que je dois réaliser

Créer le dossier atelier-git, suivre les fichiers avec Git, distinguer la zone de travail du staging, enregistrer au moins trois commits et afficher l'historique.

Durée prévue : 1 h 30 · Niveau débutant.

Livrables attendus

Résultats à fournir

  1. Un dossier atelier-git avec index.html, style.css et README.md.
  2. Un dépôt Git local initialisé.
  3. Au moins 3 commits avec messages explicites.
  4. Une capture de git log --oneline.

PARTIE 1 15 min

Configuration et création du projet

Exercice individuel du support de formation.

Travail demandé

  1. Vérifier l'installation de Git.
  2. Configurer l'identité Git (nom et e-mail).
  3. Créer le dossier atelier-git.
  4. Initialiser un dépôt Git dans ce dossier.
  5. Afficher l'état du dépôt.

Commandes à utiliser

git --version
git config --global user.name "Votre Nom"
git config --global user.email "votre@email.com"
mkdir atelier-git
cd atelier-git
git init
git status

PARTIE 3 20 min

Modifier un fichier

Exercice individuel du support de formation.

Travail demandé

  1. Ajouter un paragraphe de présentation dans index.html.
  2. Exécuter git status.
  3. Afficher les modifications avec git diff.
  4. Ajouter les modifications au staging.
  5. Créer un deuxième commit : « Ajout de la présentation ».

git diff

git diff --staged

git log --oneline
