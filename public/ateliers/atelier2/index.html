Objectif

Ce que je dois apprendre

Expliquer les principes de l'Agilité, les responsabilités de l'équipe Scrum, les backlogs, les User Stories, l'estimation et les cérémonies Scrum.

Méthode

Comment compléter l'atelier

  1. Lire les 16 questions de l'énoncé.
  2. Rédiger mes réponses avec mes propres explications.
  3. Ajouter les exemples demandés pour Quick Annonce.
  4. Vérifier les réponses puis publier des scans/photos lisibles ou un PDF.
